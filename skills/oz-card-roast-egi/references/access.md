# Источники Ozon и MPStats

## Среда и браузер

Найди доступные инструменты по названию/описанию сервиса. Префиксы MCP меняются. Локальный Chrome, встроенный браузер и облачный браузер имеют независимые входы; наличие скилла не переносит авторизацию или MCP между компьютерами.

Для Ozon Seller используй `https://seller.ozon.ru/` и существующий авторизованный браузер. Проверь видимого продавца, найди товар по SKU/артикулу, сверь вариант. Через текущий интерфейс собери содержимое карточки и доступную аналитику за выбранные даты. Названия разделов и метрик бери из интерфейса, не из памяти. Фиксируй определения, фильтры и охват схем/вариантов. Экспорт скачивай штатной кнопкой.

Если доступен Computer Use, начни с его предусмотренной инициализации и документации. После переходов используй актуальное состояние. Не используй скрытые сетевые запросы, чтение профиля браузера, cookies, localStorage, токенов или перехват запросов. Чтение скачанных файлов обычными файловыми инструментами разрешено.

Для публичной карточки проверь фактически выбранные вариант и продавца, адрес/регион доставки, цену с Ozon Картой, цену с другими банками, наличие и срок доставки. Подписывай цену ровно по видимому условию, включая персональную скидку/купон, если он действует. Текущая цена не равна средней цене продажи за период.

При невозможности открыть свой кабинет продолжи внешнее сравнение по публичной карточке. При блокировке сайта используй разрешённые выгрузки/скриншоты; не обходи защиту и не покупай тариф/подписку.

## MPStats MCP: внешний рынок

1. `list_categories` → `get_category_tools(category="ozon")`.
2. Прочитай текущие схемы выбранных инструментов; при необходимости `describe_tool`.
3. Вызывай `run_tool` с точным именем и аргументами. Только чтение.

Каталог схем проверен 28 октября 2026 года. Это проверка доступности инструментов, а не сбор бизнес-данных и не подтверждение, что все отчёты вернут нужные поля.

| Имя из проверенной схемы | Для чего использовать | Существенное условие |
|---|---|---|
| `ozon_sku` | Идентификация и отчёты `full`, `sales`, `by_period`, `categories`, `keywords`, `search_stats`, `stores`, `comments` | Числовой `sku`, явные `d1/d2`, охват `fbs`; наличие поля проверяется в ответе |
| `ozon_sku` с `by_day` / `balance` | Детальный снимок для даты | Нужен `point_date`; не предполагай, что один вызов отдаёт дневную историю всего месяца |
| `ozon_categories_search` | Найти категорию по короткому существительному | Возвращает `path`; путь не выдумывается |
| `ozon_categories_children` | Уточнить ветку | `path` из фактического ответа |
| `ozon_category` | Кандидаты через `report="products"`, контекст через `keywords` и прочие доступные отчёты | `path`, `d1/d2`, `limit`, `fbs`; в проверенной схеме нет отдельного параметра sort или offset |
| `ozon_seller` / `ozon_brand` | Проверить ассортимент продавца/бренда, исключить свои товары и дубли | Не заменяет функциональную сопоставимость |

Параметр `fbs=1` по проверенной схеме включает FBS вместе с FBO; `fbs=0` — FBO. Значение выбирай одинаковым для сравниваемых товаров и переноси фактические ограничения охвата из ответа в отчёт. Не копируй специфичные для WB предупреждения как утверждения о данных Ozon. Даты передавай явно, конец не позже вчера. Дефолт `d1=d2−30` не равен 30 дням при включённых границах.

Если ответ не содержит описания, характеристики, изображения или текст отзыва, не считай их пустыми. Получи их из реальной карточки/кабинета/разрешённого экспорта или отметь недоступность. Отчёт `comments` сам по себе не гарантирует полный текст или фильтр по варианту. В проверенном каталоге Ozon нет отдельных аналогов `wb_similar`, `wb_card_content` и `wb_check_rates`; не вызывай выдуманные `ozon_similar`/`ozon_card_content`/`ozon_check_rates`.

Ответы могут быть ограничены лимитом и не содержать полного ранжирования категории. Сохрани реальный охват кандидатов. Поля, названия и единицы определяй по ответу; одинаковое имя не делает оценки фактическими продажами продавца. Данные внешнего MPStats маркируй как оценки.

## MPStats MCP: только собственный подключённый кабинет

Если нужен свой внутренний отчёт и он есть в подключении, прочитай схемы категории `lk_ozon`. Выбирай кабинет по `lk_ozon_cabinets`; не оставляй scope «все кабинеты» при неоднозначном продавце.

- `lk_ozon_products` — поиск и привязка собственного товара/цен/наличия. Используй точный SKU и кабинет; фильтр по тексту сам по себе не доказывает совпадение.
- `lk_ozon_pulse` — фактическая воронка только товаров «в продаже». Пагинация, доступное окно дат и определения полей — по текущей схеме.
- `lk_ozon_product_daily` — дневная воронка одного точного SKU. Запрашивай только нужные группы, например `funnel`, `orders`.

В проверенной схеме RNP ограничен последним 31 днём от текущей даты и статусом «в продаже». Для более раннего периода ищи штатный отчёт Ozon Seller или пометь пробел. Не меняй период внешних конкурентов молча ради внутреннего отчёта. Изменение в % к прошлому периоду не является значением показателя за прошлый период; для проверки динамики сохрани реальные числа, период и определения.

`in_progress` допускает повтор того же запроса после `retry_after`. Не меняй аргументы между такими повторами. Не используй `lk_ozon_*` для чужих продавцов и не подменяй им внешнюю оценку своей карточки в медиане. Репрайсер, фоторедактор, управление рекламой и создание проектов не требуются.

## Резерв через интерфейс MPStats

При отсутствии MCP или по просьбе пользователя открой авторизованный `https://mpstats.io/`. Найди SKU, категорию, подходящие товары и выгрузи данные штатными кнопками. Зафиксируй даты, схемы, сортировку, цену, лимит и назначение аналогов. Если источника конкурентов нет, объясни, какая выгрузка нужна; не заполняй таблицу числами из памяти.
# Наблюдения живого прогона 28.10.2026

На SKU 1588074244 проверены MPStats MCP, публичная карточка и точная строка FBO в кабинете Vertex. `full` и `by_period` MPStats возвращали нули для собственного предложения с пометкой FBS при ненулевых FBO-заказах Seller. У ряда конкурентов `full.period_stats`, дневной ряд и `category/products` также расходились. Не считай такие нули отсутствием продаж; сохраняй их с исключением и описывай охват каждого отчёта. Даты запроса сами по себе не доказывают совпадение периода внутри `full`.

В Seller «Моя аналитика» задай даты и артикул, группировку по товарам, затем сверь SKU и схему в строке. «Скачать → Отчёт за период» даёт исходный XLSX с определениями показателей. При нескольких строках одного SKU проверь схему; пустую/нулевую строку не учитывай повторно. Конверсия «поиск и каталог → карточка» использует показы поиска/каталога и не должна называться рекламным CTR. Цена «С банками» может включать несколько банков-партнёров, поэтому не подписывай её как исключительно цену Ozon Карты.
