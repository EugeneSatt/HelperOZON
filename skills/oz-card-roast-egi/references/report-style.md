# Закреплённый стиль отчёта

Стиль по умолчанию — `paper-sky-pink-lime-v1`, перенесённый из WB-аналога по запросу «такой же для Ozon». Сохраняй его при каждом новом SKU и после переноса скилла; не предлагай повторно выбирать дизайн. Конкретные SKU, суммы и замечания из прошлых отчётов не являются частью стиля.

## Точные ресурсы

Единственный источник цветовых и шрифтовых токенов — `assets/report-theme.json`. Визуальный ориентир — `assets/style-preview.png` (нейтральный демонстрационный макет, его числа не использовать в аудитах). Сборщики и шрифты входят в пакет. Не загружай шрифты из интернета во время очередного прогона.

| Роль | Цвет |
|---|---|
| Бумажный фон | `#F1EBE2` |
| Почти чёрный текст | `#20211E` |
| Небесно-голубые блоки | `#A8CEDF` |
| Розовые блоки | `#EDA4B9` |
| Лаймовый маркер | `#DFED68` |
| Тихие подписи | `#625F58` |
| Рамки карточек | молочный `#FCF9F3` |

Заголовки — упакованный **WB Roast Display Black**, узкий тяжёлый шрифт на основе Roboto Condensed Black. Основной текст — **Roboto Regular/Bold**, рукописные заметки — **Caveat Bold**. Это переносимые замены системных шрифтов первого макета, с кириллицей. Все четыре TTF и лицензии лежат в `assets/fonts`; происхождение, изменения и контрольные суммы — в `manifest.json`. Не заменяй их случайным доступным шрифтом.

## PDF

- A4, поля 30 pt. Крупные узкие чёрные заголовки, плотная вертикальная композиция, обычный читаемый текст 9–11 pt. Подписи 7,5–8,5 pt.
- Обзор: слева заголовок «Карточка под лупой», справа голубая бумага с реальной обложкой в слегка повёрнутой рамке и кусочком скотча. Индекс обведён лаймовым маркером. Под ним всегда видимое покрытие; это не универсальная оценка качества.
- Показатели Ozon Seller — крупные числа, ниже розовая полоса воронки. Отсутствующие числа — прочерк, никогда не демонстрационная подстановка.
- Действия: до трёх нумерованных бумажных полос с голубым, розовым и лаймовым акцентами; факт, гипотеза, действие и проверка читаются отдельно.
- Сравнение: настоящие первые обложки в молочных рамках. Не перекрашивай фотографии товаров под палитру. Если обложка недоступна, оставь явный текстовый пропуск.
- Декор: немного ручных стрелок, неровные овалы маркера, звёздочки, тонкие линии и едва заметная бумажная фактура. Декор не закрывает данные и оговорки. Не добавляй портрет, чужой логотип или одежду из исходного референса.
- Встраивай TTF в PDF. Такой файл сохраняет типографику на другом компьютере без установки шрифтов. Дату, кабинет, артикул, доли и знаменатель бери из текущих данных.

## Excel

Четыре существующих листа и типизированные значения сохраняются. Молочный фон на ограниченном рабочем диапазоне, чёрные шапки с молочным текстом, заголовки WB Roast Display Black, основной текст Roboto, без стандартной сетки. Отдельные голубые, розовые и лаймовые блоки связывают книгу с PDF. Нельзя прятать ограничения ради декоративного блока.

Семантика статуса сохраняется, отображение берётся из `status_palette`: `green` → голубой (выше / есть), `yellow` → лайм (на уровне), `red` → розовый (ниже), `nodata` → серый, `info` → бумага. Легенда обязательна: нельзя читать розовый цвет как доказательство плохой карточки.

Шрифты для предпросмотра загружаются из пакета в процесс. Сам формат XLSX не встраивает обычные TTF в ячейки: для точного отображения редактируемой книги в Excel на другом компьютере установи четыре приложенных TTF средствами ОС. Не обещай идентичные шрифты XLSX без этого условия и не меняй системные настройки молча. PDF остаётся переносимой версией для просмотра и пересылки.

## Перенос и проверка

Передавай весь архив `.skill` / каталог `oz-card-roast-egi` с `assets`, `scripts`, `references`, `agents` и `SKILL.md`. Не помещай в пакет кабинеты, cookies, скачанные бизнес-данные, старые `audit.json`, окружение Python, `node_modules` или абсолютные пути исходного компьютера.

После обновления проверь расчёт и сборщики. Для проверки переносимости распакуй пакет в другую временную папку, выполни сборку по нейтральным данным без обращения к системным шрифтам и отрисуй PDF. Перед реальным выпуском визуально проверь все страницы PDF и листы Excel; пустые данные и другое число конкурентов не должны ломать тему.
