## Как переносить на другие товары

- Сохраняй ритм «крупный заголовок → товар или узнаваемая сцена → короткие факты». У Purelamby узнаваемость держится на небе, облаках, листьях, пузырях и маскоте. Для нового товара выбери свою фирменную среду и конкретные элементы, которые продолжаются через стыки.
- В референсе основная задача — показать ассортимент. Для одного SKU тот же ритм можно провести через главы о пользе, сценарии использования и важных характеристиках. Инструкцию и совместимость добавляй по потребности покупателя и подтверждённым данным. Остальную линейку показывай по запросу.
- Держи связанный текст внутри одной части даже там, где фон или предмет проходит через границу. В референсе строки вводного текста попадают на разные изображения. Для нового рича проектируй границы под свой текст и профиль экспорта из [ozon-production.md](ozon-production.md).
- Формулировки и численные обещания подбирай для конкретного товара по его источникам. Иконки и сцены объясняют подтверждённое свойство, а доказательство берётся из исходных материалов.
